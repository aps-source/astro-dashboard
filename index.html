This dashboard is a snapshot, not a continuous live feed — Astro has no single always-on local engine (unlike a ticking indicator strategy); entries and exits are placed by independent scheduled cloud routines, and this Dhan account also runs several other live strategies trading the same underlyings, so polling raw Dhan positions here could not reliably tell Astro's trades apart from theirs. Data comes from this project's own trade_log.json (built by pulling the 7 Astro routines' own run logs) and plan_compact.json — refreshed on request ("sync the Astro trade log, then update the dashboard"), not automatically.
